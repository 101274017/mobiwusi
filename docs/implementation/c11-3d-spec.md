# C11 3D 导入支持规格草案

更新日期：2026-10-16（Asia/Shanghai）。这是 C11 的本地预检与候选矩阵，不是 E20/F03 的真实渲染验收，也不是对任意版本和资产的兼容承诺。

## 候选矩阵

| 格式 | 内容识别 | 候选版本 | 材质边界 | 动作骨骼边界 | 端侧范围 |
| --- | --- | --- | --- | --- | --- |
| VRM | GLB 头 + glTF JSON + VRM 扩展 | `0.x`、`1.0` | `PBR`、`unlit`、`MToon`、默认材质 | 有 VRM humanoid 才报告动作兼容；无骨骼只显示 | 电脑候选；Android 禁用 |
| FBX | Binary/ASCII 头；不把头部识别当兼容证明 | `7.4`、`7.5` | 由隔离解析器摘要确认 | `humanoid` 摘要才报告动作兼容；其他只显示 | 电脑候选；Android 禁用 |
| GLB | GLB 头 + glTF 2.0 JSON | `2.0` | `PBR`、`unlit`、默认材质 | 标准人形摘要才报告动作兼容；否则只显示 | 电脑候选；Android 禁用 |

所有格式只允许当前本地文件。外部 URI、脚本/shader/可执行引用、未知扩展、损坏容器、未知材质和超限资源均拒绝导入并回退到原配置/2D。文件名和扩展名只用于显示或用户声明校验，不作为格式兼容证明。

## 候选资源预算

- 文件不超过 `50MiB`。
- 贴图单边不超过 `2048px`。
- 三角面不超过 `100,000`。
- 隔离解析峰值不超过 `512MiB`。
- 解码资源候选不超过 `300MiB`。
- 解码展开比例超过 `100x` 按压缩炸弹处理。

这些数字对应技术方案中的 C 阶段起始预算，仍需低端 Windows 集显、混合 DPI、多屏和真实渲染宿主测量后冻结。C11 只实现纯本地容器/摘要预检：GLB/VRM 能解析基础头与 JSON；FBX 仅识别容器并要求隔离解析器摘要。没有引入 Three.js、three-vrm、FBXLoader、供应资产或网络下载。

## 失败与回退

`preview_allowed` 只表示通过本地结构、版本、材质、骨骼摘要和资源门控，仍保留人工复核要求。`display_only` 表示可以展示模型但不能假装动作兼容。`review_required` 表示需要隔离解析器或人工复核；其他安全/预算/兼容失败统一 `fallback_2d`。失败时不替换旧桌宠配置，不上传本机资产，不开放 Android 3D 入口。

证据：`evidence/c11-3d-results.json`、`evidence/c11-3d-scope.json`、`tests/domain/three-d-asset-preflight.test.ts`。
