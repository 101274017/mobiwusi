# 前端三场景演示脚本

更新日期：2026-10-16（Asia/Shanghai）。本文件把 PRD 6.1 的场景 A/B/C 转成可重放的前端演示步骤，服务于 B07/B10/FE-13；只证明共享前端和合成夹具，不替代 C/D 的设备、真实服务或人工签收。

## 通用准备

1. 在仓库根目录执行 `pnpm dev`，确认服务模式为 `mock`。
2. 打开 `/development/scenarios`，选择场景后使用“重置当前场景”；每个场景使用独立 `ownerId`，不得把一个场景的本机资料当作另一个场景的证据。
3. 记录场景 ID、浏览器视口、构建产物 hash、步骤、预期、实测结果和失败截图；证据只使用合成资料，不录入真实账号、密码、验证码、屏幕或音频。
4. 通过 `pnpm check` 验证共享单元/边界结果；本轮双视口 E2E 证据写入 `docs/implementation/evidence/e2e-results.json`，仅当实际重跑且浏览器可用时更新本轮 E2E 执行结果。

## 场景 A：老人学习视频通话

**PRD目标：** 用户提出学习需求，完成应用内逐步教学，留下笔记，创建复习提醒，并在授权边界内查看学习进展。

1. 进入 `/#/chat/new?scenario=success`，使用合成问题完成分段讲解，确认字幕/语音降级和“再讲一遍”均可用。
2. 进入 `/#/overlay/guide?scenario=success`，点击“开始练习”及“确认开始练习”；每一步只在用户点击后推进，不模拟代点击。
3. 在完成页进入笔记入口，确认笔记标题、来源和掌握状态可见；刷新页面，确认本机资料仍在。
4. 进入待办/复习入口，创建一个具体日期和时区的复习事项；确认实例 ID、应用内深链和版本字段存在，浏览器端状态保持 `page_only`。
5. 进入 `/#/family?scenario=success` 或协助入口，使用合成关系完成“仅在确认后查看进展”的演示；不得把模拟关系称为真实授权。

**必须观察：** 教学停止后无迟到步骤复活；提醒 `submitted` 不等于系统 `delivered/opened`；浏览器不冒充后台提醒；协助只使用合成状态。

## 场景 B：儿童作业辅导

**PRD目标：** 儿童通过手绘生成可预览的 2D 桌宠，获得分步讲解，把未掌握内容写入笔记并创建次日复习。

1. 进入 `/#/pets/draw?scenario=success`，绘制或保留合成画稿，使用“演示生成任务流程”并手动启动；确认预览标记为演示/原画，不能显示为真实 AI 生成。
2. 点击“确认保留演示预览”，刷新页面，确认画稿和确认状态保留；使用失败夹具时确认草稿保留、不会覆盖旧配置。
3. 进入 `/#/chat/new?scenario=success`，提交合成作业问题，确认讲解分段显示；在中断/部分失败夹具下确认不生成完整笔记。
4. 在笔记中确认“乘法进位”等未掌握内容的合成状态，再创建次日复习事项，确认深链直达该笔记/教学入口。
5. Windows 3D 导入仅按 C11 预检矩阵单独演示，不能作为场景 B 的必需前置，也不能把 VRM/GLB/FBX 预检称为设备渲染通过。

**必须观察：** 生成失败保留草稿；儿童模式、账号和设备命名空间不串数据；手机不提供 3D 入口；真实 AI、儿童理解和可动资产仍未接入。

## 场景 C：误入支付与教学失败

**PRD目标：** 命中交易风险时立即停止共享/指引并转人工确认；陌生安全页面无法识别时坦诚失败，只能在明确授权后邀请已绑定家属。

1. 进入 `/#/overlay/guide?scenario=risk-pause`，开始并确认练习，触发“模拟转账页面”；确认出现“安全暂停”，目标指示停止，且没有自动恢复。
2. 点击“我已离开风险场景，重新确认”，确认再次出现开始确认对话框；只有用户确认后才恢复应用内练习。
3. 进入协助入口，使用三种本机夹具分别演示邀请状态：正常路径直接接听；过期路径使用 `?scenario=invite-expired`（或协助地址追加 `?assist=expired`）；无人接听路径在正常场景的协助地址追加 `?assist=unanswered`，会在短延迟后结束。过期和无人接听均不能接听、不会建立共享，并提供“重新发起演示邀请”；结束或失败不自动重连。
4. 记录安全状态、停止事件、邀请状态和回退文案；不上传原始画面、验证码、支付信息或真实联系方式。

**必须观察：** 风险暂停不能通过更换 Mock 场景绕过；真实微信/支付/陌生网页捕获、检测、媒体出口和电话流程仍属于 C/E/F，未有设备或真实供应证据时保持关闭。

## 证据分级与结论

| 证据 | 能证明 | 不能证明 |
| --- | --- | --- |
| 页面操作/合成夹具 | B07 前端交互、失败回退、资料隔离和可重置 | 真实账号、AI、系统权限、跨应用教学、后台通知 |
| `pnpm check` 与本轮双视口 Chrome E2E 报告 | 共享代码和固定视口自动化回归 | 本轮真实设备或人工读屏签收 |
| Android/Windows 预备包 | 宿主边界、编译和静态/合成规则 | NV 实测、系统投递、真实媒体、D Go/No-Go |

当前三场景的前端重放脚本已具备，场景 C 的正常/过期/无人接听夹具可在本机快速重放；B07/B11 的人工演示、C15 独立复核和 D 关口仍待负责人、设备和真实资源到位。
