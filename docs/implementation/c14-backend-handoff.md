# C14 后端契约自动技术冻结与交接

更新日期：2026-10-18（Asia/Shanghai）。本文件按实施计划双门禁规则及独立桌宠改版说明 C14 的自动技术冻结与开发交接。技术冻结必须来自实际契约、版本、兼容性与消费者检查，不以人工签字作为本地开发前置；不代表独立人工评审、后端部署或正式 D07 Go。

## 交接基线

- 单一来源为 `packages/contracts/src/spec/`；契约版本、操作数和服务定义数以当前源文件及实际检查报告为准，不由本文固定为草案或已通过。
- 生成物包括 OpenAPI 3.1、JSON Schema、TypeScript DTO 和 Kotlin DTO。不得直接修改生成文件；接口变更必须回到源定义并重新生成。
- 自动审查命令为 `pnpm c14:handoff:check`，结果写入 `docs/implementation/evidence/c14-handoff-results.json`；只读复核可运行 `node scripts/check-c14-handoff.mjs --no-write`。

## 证据可追溯性

- 报告的 `generatedAt` 是带 `Z` 的 ISO 时间戳，`generatedDate` 和 `generatedTimeZone` 单独记录 Asia/Shanghai 日期/时区，避免只用日期造成时间顺序歧义。
- `sourceInventory` 记录生成的 OpenAPI 和六个契约源文件（含 standalone guidance）的相对路径、字节数与 `contentSha256`。本轮实际基线为 61 个操作、127 个定义。哈希只标识读取的本地文件版本；自动技术冻结还须核对实际检查、命令退出码与当前相关版本，不能仅凭哈希宣称冻结或部署。

独立桌宠分析是单独的鉴权只读 POST：可选关联头、无幂等头要求、真实失败状态与专用关联错误包络，不改变旧操作的幂等/版本边界。请求中的安全与脱敏字段只是客户端声明，不代表服务端证明本地检测；完成与复习建议也不能代替当前新帧核验或本人确认。
- `blockerRefs` 为每个 D/E 前置缺口分配稳定代码；`blockers` 保留给人阅读的原因。缺口代码、来源哈希和审查结果必须一起归档，不能用重新生成报告的时间替代源文件版本。
- 当前检查器默认使用 development 模式。实际本地检查及其执行命令通过时可得到 `status=frozen`、`technicalFreeze.status=frozen`、`technicalFreeze.freezeType=automated_technical`；失败应报告 `technical_blocked` 并修复，不得伪造通过或改记外部待项。
- `backendStarted:false` 只限定 C14 检查动作未启动后端，不是对仓库已有后端实现的判断，也不禁止后续本地开发。独立评审仍单列外部待项，自动技术冻结不等于人工复核或正式批准。

## 开发交接与依赖

- D07 自动开发结果为 `DEV_READY` / `DEV_READY_WITH_EXTERNAL_PENDING`，且相关前置的 development 状态满足 FS/SS/FF 时，可继续 E/F 本地代码、数据库与服务、契约夹具和自动测试；不等待独立评审、真实供应或人工正式 Go 后再编码。
- FS/SS/FF 继续约束代码之间的先后关系；开发读取 development，真实设备、供应、参与者同意、试点及发布读取对应 verification，不能把两者混作一个全局 blocked。
- 当前用户要求先跑 F，应向依赖已满足的 F 本地检查交接；实际契约、安全或证据失败仍须修复，不能借开发通过开放未验证的生产能力。

## 必须保留的边界

### 身份、关系与同意

- 公共挑战只允许出现在 `/v1/auth/`，并绑定一次性证明、设备签名、运营商或供应证明；浏览器本机状态不能直接兑换服务端会话。
- 关系 scope、当前 grant revision 和当次 consent 分开校验。家属接听不等于被协助端已授权屏幕、音频或摄像头。
- 撤销关系、撤回同意、撤销设备必须立即阻断新增访问；缓存或迟到结果不得恢复出口。

### 幂等、版本与取消

- 非 GET 操作必须带 `Idempotency-Key`；版本化写操作使用 `If-Match`，成功响应返回 `ETag`。
- 笔记、待办、关系授权、桌宠当前资产等对象拒绝降版本覆盖；冲突返回安全错误包络和当前版本信息，不静默合并。
- 流式请求、讲解、生成任务和协助都必须有显式 cancel/stop/end 语义；关闭 SSE 不得被当作业务成功。

### 媒体租约与停止

- 上传创建、指导分析/核验和对话响应都要求当前采集或媒体同意；二进制上传受生成的 10MiB 上限与短期安全上传授权约束。
- C03/C04 本地安全票据、脱敏和双出口 stop fence 先于任何编码/发送；服务端接口不得把客户端声明当作检测通过证明。
- `assistJoin` 只签发当前参与者、设备和 grant revision 绑定的 `relay_only` 短期凭证；`assistEnd` 要求本地先停止，服务端租约只作兜底。
- 只能接收真实可观测的提醒回执；`submitted`、`delivered`、`opened` 和 `completed` 不得互相冒充。

## 交付边界

- C14 交付自动契约审查、技术冻结记录与交接输入；本次文档更新本身不实现或验证账号、AI、语音、生成、同步、媒体或数据库服务，也不限制后续按开发门禁实施这些本地业务能力。
- 自动技术冻结、本地代码实现、自动测试和正式验收分别记录。独立评审、真实供应、真机、真实试点与发布仍为 external_pending；受影响生产能力默认关闭，并须验证拒绝路径。
- 不把 Mock、合成账号、静态检查或自动复核写成真实服务接入、有效用户授权、人工签收或正式完成；正式 D07 门禁不因本地开发通过而解除。
