## 后续证据记录格式

开发证据记录实际命令、退出码、环境、相关版本/指纹、覆盖与限制，自动复核标 automated。哈希仅证明内容一致，不证明测试真实执行；真正的本地编译、契约、安全或证据错误必须修复，不能改记 external_pending。

每次 NV/真实 AT 执行仍须记录：日期、版本/包哈希、设备型号/OS/DPI、用例和合成素材、前置权限、操作步骤、预期、实际、帧/编码/发送/接收/缓存计数、截图或视频、限制和真实执行/复核来源。不得填写虚构人员；这些是实际验证发生时的来源要求，不是现在向用户补要角色或签字才能开发。

敏感素材只使用明确合成的 canary，例如 SAFE-CANARY-OTP-123456；不能用真实密码、验证码、银行卡或儿童素材。扫描器先验证能检出故意注入的 canary，再判定零泄漏。纯文本规则测试不能代替屏幕帧检测。
