# 单帧图片指引（试验入口）

## 使用路径

桌宠右键功能清单 → 光标指引 → 单帧图片指引 → 选择共享屏幕或框选区域 → 确认本机截帧 → 检查脱敏图片 → 输入问题 → 仅分析此帧 → 再次确认发送。

此模式会先停止旧的连续观察，不会自动恢复。已有客户端管理界面不改变。当前已启动的进程需要重新加载新版本才会出现入口，不因代码修改自动重启。

进入单帧后使用独立预览及提问区，暂时隐藏原连续观察的输入区；点击“返回连续观察指引”可恢复原界面，但不会恢复采集。切换到其他功能会取消在途单帧请求并清除预览。

## 与连续观察的区别

- 使用独立受控 Windows 屏幕来源、独立授权和取消状态，不借用旧持续观察的云端授权。
- 只读取用户选定范围的一帧；先本地 OCR/人脸检测、敏感检查、脱敏，再预览实际待发送的 PNG。文字与人脸遮盖，因此不保证能识别被遮盖的文字。找图标时优先框选图标区域。
- 预览不调用 AI；只有再次确认后才通过已配置的真实图片服务发送这一张图片和问题一次。预览有效期两分钟，请尽快发送。失败不会自动重试。
- 单帧路径保留真实脱敏画面，不把未分类桌面替换成控件布局；旧 `evaluateLocalFrame` 的场景白名单门控保持不变。敏感内容与检测失败仍阻断。
- 模型只能返回严格 JSON：`kind`、`instruction`；定位时还须包含 `label`、图片像素 `rect` 和 `confidence`。边界非法、额外字段、解析失败或置信度不足均不绘制猜测位置。
- 收到位置后，仅本机重新截帧及脱敏，检查来源标识、屏幕几何和目标区域像素，复核帧不上传。屏幕或目标变化则要求重新截帧。
- 采用已验证的截图像素 → 所选区域屏幕 DIP 几何映射，支持负屏幕原点与缩放；不重复叠加框选偏移。
- 复用既有透明置顶、鼠标穿透的只读指引窗口。AI 图像定位以“可能是这里，请先核对”展示，最长五秒；窗口不能显示则报错，不假报成功。
- 不移动系统鼠标，不自动点击、输入或打开软件。用户亲手操作后，再截下一帧，不自动宣称任务完成。
- 取消、锁屏、休眠、显示器变化、渲染进程退出和应用停止会清除预览及取消在途分析。PNG 仅短暂保留在内存；不新增截图、原始 AI 响应或凭证日志。

```powershell
pnpm exec vitest run tests/platform/desktop-single-frame-guidance.test.ts tests/platform/desktop-standalone-host.test.ts tests/platform/desktop-pet-ui.test.ts
pnpm exec playwright test tests/e2e/desktop-pet-single-frame.spec.ts --project=desktop-chromium

```

单元及浏览器测试使用明确标识的合成图片/模拟 AI，覆盖链路、隐私隔离和 UI；它们不是本机真实桌面或真实模型识别准确率的证明。真实验收需在运行新版本的 Windows 桌宠中，由本人选择范围、检查预览并确认发送，观察实际微信图标是否被正确框选。未完成此项前，不报告真实桌面验收通过。
