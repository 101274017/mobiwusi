## 不可跳过的边界

- 门控位于原生媒体发送前，未知/检测故障默认不发；浏览器文字规则不冒充帧检测。
- 任何活动路径可停止；停止后迟到事件不能复活，刷新不自动开启采集或协助。
- 用户亲手操作后重新核验；练习完成、待办完成、掌握确认分别记录。
- 关系、档案 scope、当次共享同意和系统授权独立，不以其中一个替代其他。
- 服务模式与平台模式独立；真实服务失败不得回退 Mock，真实模式不加载演示账号。
- 预览原画或内置动画不等于生成可动资产；扩展名正确不等于 3D 格式支持。
- D 未通过不进入 E；没有真机/供应报告，不把纯函数和浏览器测试记为 NV 通过。

## 契约现状与差异

新增 JSON Schema 覆盖流式开始/分段/完成事件与安全错误包，运行时检查请求 ID、序号和完整结束。现有活动桥开放 capabilities/stop_all 及严格受限的 reminder_schedule/reminder_cancel/reminder_notify_due；未实现方案中的媒体、权限、资产等其他桥方法。HTTP/SSE/WS 全量 DTO、权限协议、后端 mapper 与评审冻结仍待 A02/A03/C14/D02，不把当前契约草案声明为已冻结。

当前真实本地存储为浏览器 IndexedDB，版本 3 新增 pet-jobs 并保留 v2 的账号与画稿。它不能代替计划中的 Room/SQLite。任务 Mock 的 source=simulation、generated=false，确认不会更换当前桌宠。
