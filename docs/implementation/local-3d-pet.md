# 本地 3D 模型导入与独立桌宠

> 文档同步：2026-10-22。产品显示名称为**微光指引**；[当前功能与平台边界](product-current-state.md)统一说明现行入口、已实现范围和待验证能力。本文已有测试数字与生成日期仍只对应原批次，不因文档更新自动视为重新验收。

## 本次范围

电脑客户端“我的小伙伴”新增真实入口：选择本地模型 → 本机安全检查 → 旋转预览 → 本人点击“确认设为独立桌宠” → 独立悬浮窗口使用模型。不是删除提示或伪造导入成功，不调用 AI 生成服务，也不上传模型。浏览器和 Android 只显示电脑端能力说明，不能选择文件。

支持有边界的 GLB / glTF 2.0、VRM 0.x / 1.0、FBX 7.4 / 7.5（ASCII 及二进制）。播放文件自带的第一段动画；没有动画则作静态 3D 展示。不会自动生成人形动作、把普通骨骼转换成标准骨骼，或承诺全部供应模型和教学动作兼容。减少动态效果偏好会停用自动播放。

## 操作

1. 正常重启电脑客户端，以加载新的主进程与 preload。
2. 从独立桌宠右键菜单打开“我的小伙伴”，或在管理客户端进入该页。
3. 在“让你的 3D 伙伴，来到桌面”选择本地文件，等待隔离检查完成。
4. 在预览区拖动旋转、滚轮缩放，确认模型外观及动画。选择和预览不会替换桌宠。
5. 点击“确认设为独立桌宠”。关闭管理窗口不关闭桌宠；重启继续使用本机副本，不依赖源文件原路径。
6. “切回原画 / 内置桌宠”经本人确认后回到之前的 2D 形象；保存的画稿和选取的源模型文件不删除。重新应用原画或恢复内置形象也会停用 3D，避免两种形象重叠。

## 格式与稳定性边界

- 单文件不超过 50 MiB，三角面不超过 100,000，节点不超过 2,048，网格不超过 512，骨骼不超过 512，材质不超过 256。
- 纹理必须内嵌，只接受可识别的 PNG / JPEG / WebP；单边不超过 2,048，纹理数量不超过 128，按保守估算的解码资源不超过 256 MiB。
- GLB / VRM 只接受内嵌 BIN、三角网格和已列入白名单的材质/VRM 扩展；外部纹理、脚本、自定义着色器、稀疏访问器、Draco / Meshopt / KTX 压缩均拒绝。不能仅修改文件后缀绕过检查。
- FBX 二进制在主进程先核对节点/数组边界，压缩数据使用有输出限额的解压核验；ASCII 核对格式、结构数量和内嵌图片。真实 FBX 解析由隔离窗口执行，外部纹理一律不读取。建议导出资源内嵌的 GLB 以减少格式差异。
- 真实解析在独立非持久 session 的沙箱窗口完成，20 秒超时；每 400ms 采样检查解析进程私有内存，超过 512 MiB 即停止。这是采样保护，不代表已证明所有硬件上的瞬时峰值。
- 解析窗口拒绝系统权限、外部导航及网络请求，只加载固定本地页面、固定渲染包和内存资源。管理及桌宠仍保持 sandbox / contextIsolation / webSecurity，Renderer 不获得文件路径、Node、任意 IPC 或网络上传能力。
- 预览及桌宠均校验真实首帧有可见像素；材质编译失败、WebGL 不可用或上下文丢失给出说明并回退，不把空白画面当成功。
- 启动、导入和预览均不启用屏幕观察或麦克风。

## 存储与确认边界

原生文件选择器只由受信任管理窗口调用。文件内容经过检查后进入内存暂存，预览令牌只可用一次、10 分钟过期；选择新的文件会使旧令牌失效。应用时只接收令牌，不接收 Renderer 指定的文件路径或模型字节。

确认后的模型、副本哈希和解析摘要保存在固定用户目录下的 `nuanban-local-model.sqlite`，使用同步提交的 SQLite 单语句事务，避免本机图片目录重命名返回 EXDEV 的问题。写入失败不改变上一条记录；启动时重新核对模型内容哈希与格式。原画仍使用原有 PNG / 恢复文件仓储，画稿仍在 IndexedDB。

## 验证

在仓库根目录执行：

```powershell
pnpm typecheck
pnpm exec vitest run tests/platform/desktop-local-model.test.ts tests/platform/desktop-local-artwork.test.ts --maxWorkers=1 --no-file-parallelism
pnpm --filter @nuanban/web build
pnpm desktop:model:check
pnpm desktop:artwork:check
$env:PLAYWRIGHT_CHANNEL = 'msedge'
pnpm exec playwright test tests/e2e/local-model.spec.ts --workers=1
```

`desktop:model:check` 只创建随机临时目录、独立用户资料和合成模型，不读写真实用户画稿或应用设置。它在真实 Electron / WebGL 中检查静态和带动画 GLB、VRM 0.x / 1.0、ASCII 和压缩二进制 FBX，核对首帧像素、选择取消、外部引用和坏文件拒绝、独立运行、重启恢复、原画双向切换及采集默认关闭。

设置 `NUANBAN_MODEL_PROFILE_PARENT` 可在指定目录下创建独立随机资料子目录，验证该文件系统上的 SQLite 模型提交与重启恢复，不使用其已有数据库或画稿。测试结束只删除自己创建的临时子目录。浏览器检查使用本机已有的 Edge，无需下载另一个浏览器。

这些结果证明当前本机运行链路，不替代真实用户模型、MToon 全材质组合、各显卡性能和 F 阶段设备兼容验收。构建产物 `apps/desktop/model-runtime` 由 web 构建生成并随桌面应用打包，不提交依赖源码或构建 JS。
