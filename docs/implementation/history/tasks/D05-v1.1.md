## 范围与安全边界

- 只允许以 `apps/desktop/native-lab` 的固定合成窗口 `NUANBAN-C02-SYNTHETIC` 作为人工捕获验证来源；不得打开真实聊天、支付、验证码、账号或含第三方隐私的窗口。
- native-lab 不枚举其他窗口、不读取桌面、不接收文件、不打开链接；不启用摄像头/麦克风、编码器、WebRTC、文件写入或网络出口。
- 自动化必须保持零真实桌面媒体请求；合成轨道是 canvas `MediaStreamTrack`，不是 desktop media；不保存采集帧。
- `setIgnoreMouseEvents(true, { forward: true })` 的配置、合成按钮可点击或自动化截图只能证明配置边界，不能写成真实穿透通过。
- 所有停止都必须先失效当前 `generation`，再停止轨道并等待页面确认；迟到回调不得恢复旧会话。窗口移动、显示器变化、锁屏/挂起和渲染器退出应保守停止。

## 复现入口与执行限制

以下命令只用于复现既有预检或打开人工实验入口；命令退出码或报告 `passed` 不等于 D05 通过：

```powershell

pnpm desktop:lab:package
pnpm desktop:lab
pnpm build
pnpm desktop:package

pnpm desktop:reminder-store:check
```

- `desktop:lab:check` 必须继续证明 `realDisplayMediaRequests=0`、`displayRequestCount=0`，不得为了取得“通过”而启动真实桌面媒体请求。

- 真实人工验证只允许固定合成窗口；不保存采集帧、不输入真实密码/支付/验证码/账号、不上传或外传屏幕内容。
