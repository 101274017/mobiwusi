## 能力边界与安全不变量

- C03 只接受严格的合成帧元数据；票据绑定 `frameId`、`frameHash`、`generation`、`policyVersion` 和短时有效期。未知、失败、超时、过期、错代际、风险帧或脱敏失败应保守拒绝/暂停。
- C04 只消费 C03 安全票据和最小合成元数据，安全帧进入有界队列后才调用注入编码器，并按同一安全 artifact 送往两个本地内存出口；停止会关闭门控、递增代际并清理队列。
- C12 只允许合成夹具或受控引用元数据；无有效凭证时保持 `blocked`，不产生供应事件。现有范围记录固定 `networkAttempted=false`、`rawPayloadsRetained=0` 的零网络/零原始载荷边界。
- `packages/media-relay` 当前不创建 `MediaRecorder`、WebRTC、`RTCPeerConnection` 或 `WebSocket`，不执行 `fetch`；`packages/provider-sandbox` 不读取环境变量/密钥文件、不发起 HTTP/SSE/WS、不调用真实供应商。
- 上述不变量是当前预备范围的安全限制，不是未来真实网络接入、供应商行为或生产可用性的承诺。

## 真实缺失项与解阻条件

1. **真实媒体链路**：补齐真实设备/系统授权、屏幕或音频帧、OCR/风险/人脸模型版本、编码格式与参数、编码前门控、帧/字节/时间计数、停止与撤权后的无新发送，以及异常/丢包/重连/长时记录。
2. **WebRTC 与接收端**：在批准的拓扑下补齐 offer/answer、ICE/连接状态、候选与中继配置、发送/接收包和字节计数、断线/停止记录、AI 与家属接收端 canary；不得用本地内存出口替代真实接收端。
3. **六类供应能力**：为 `carrier_auth`、`face_auth`、`multimodal`、`asr`、`tts`、`pet_generation` 通过受控渠道登记真实凭证状态、有效期、授权范围、区域、价格/配额、回调验签、防重放、质量和取消行为；秘密不得写入仓库或证据文件。
4. **数据与合同**：补齐原始音频/图像/视频、请求/响应、日志/备份、训练用途、删除 SLA、跨区域处理、子处理方、合同版本及预算/计费结论；未完成 Q-10/Q-15 审阅前不得处理真实敏感数据。
5. **人员与关口**：补齐真实执行者、人工签收、独立复核者、C15 逐项记录、C16 决策输入、C14 独立评审/契约冻结和 D07 有权限负责人 Go/No-Go；自动化或模板不得代填这些身份与结论。
