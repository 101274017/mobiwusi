## 2. 验收依据与前置约束

### 2.1 需求范围

- `SUB-01`：讲解期间显示与当前播报语义对应的字幕；字号可调，默认语速偏慢且可调；下一步开始后不得继续显示上一条指令。
- `SUB-02`：关闭语音后仍可用完整纯字幕继续对话、教学和提醒；TTS 不可用不得阻塞讲解完成。
- `SUB-03`：字幕与桌宠、步骤和安全提示协作；大字号、横竖屏和不同窗口尺寸下不得截断关键内容或遮挡目标、停止入口。
- `AT-15`：以最大评审字号、慢语速、静音和 TTS 故障复核；完整讲解可读，关键按钮和目标不被遮挡。

## 3. 已有浏览器自动化证据

### 3.1 用例映射

`tests/e2e/accessibility.spec.ts` 的五个用例分别在 `desktop-chromium` 和 `mobile-chromium` 执行。本轮完整 E2E 结果记录为 96 项通过、0 失败、0 flaky、0 跳过，无障碍文件对应 5 个用例 × 2 个浏览器项目。`mobile-chromium` 是 Pixel 7 视口模拟，不是真机 Android 读屏或原生字幕验收。

| 编号 | 自动化检查 | 已证明的行为 | 未证明的边界 |
| --- | --- | --- | --- |
| A11Y-A01 | 键盘跳过导航、进入主内容并激活首页入口 | `body` 获焦后 Tab 到跳过链接；Enter 后主内容获焦；主要导航链接可用键盘激活并进入对话页。 | 未覆盖全站 Tab 顺序、焦点可见性、键盘陷阱、系统级键盘辅助功能或真实用户完整路径。 |
| A11Y-A02 | 最大字号、减少动画、移动视口无横向溢出 | 正文设为 `1.25`、字幕设为 `40`、勾选减少动画；正文字号增大；设置和对话页无水平溢出；对话页显示“大字字幕”。 | 未证明 Windows/Android 系统字号、显示缩放、旋转、原生浮层、长文本和复杂教学目标下的可读性及不遮挡。 |
| A11Y-A03 | 静音后字幕与重读入口仍可用 | 静音状态为 `aria-pressed=true`；发送问题后字幕包含问题要点；“再讲一遍”可用；刷新后静音状态保持。 | 未证明真实 TTS、慢语速、真实音频与字幕同步，也未证明两端原生字幕浮层。 |
| A11Y-A04 | 语音不可用时降级到字幕 | 将浏览器 `speechSynthesis` 置为 `undefined` 后，显示降级提示，字幕保留讲解内容，完成流程不被阻塞。 | 这是浏览器故障夹具，不是 Android/Windows 系统 TTS、权限或设备音频故障验证。 |
| A11Y-A05 | 模态框名称、Escape 关闭与焦点回收 | 对话框有可访问名称；打开后关闭按钮获焦；Escape 关闭；焦点回到触发按钮。 | 未覆盖读屏器实际朗读、所有模态框或移动端原生返回行为。 |

### 3.2 证据等级与一致性

这些断言属于 `ui`/`mock` 层。Playwright role、label、focus、ARIA 状态和文本断言是页面可观察行为，不等于 `device_verified`，也不等于读屏器真实朗读。证据入口为 `docs/implementation/evidence/e2e-results.json` 与 `e2e.txt`。

当前 `e2e-results.json` 的汇总为 96 项通过；D 关口记录的 D08 `e2eEvidenceExpected` 为 92。两项计数并列保留，不以较小值覆盖较新验证记录，也不影响 D08 的 `blocked` 判定；后续重跑 D 关口时须核对计数来源。
