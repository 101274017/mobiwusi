## 核心变化

| 维度 | 原工程行为/旧验收准备 | 改版要求及本轮方向 |
| --- | --- | --- |
| 产品入口 | 管理窗口与应用内模拟手机练习为主 | 启动独立透明桌宠，指引与字幕是单独只读浮层，管理窗口按需打开 |
| 窗口生命周期 | 界面生命周期和预备清理链耦合 | 关闭管理不退出桌宠；本人退出、锁屏、撤权及捕获失效须真实清理 |
| 教学对象 | 管理 DOM/合成手机页面 | 本人选择的真实系统屏幕；不把 DOM 或合成图当作第三方软件验收 |
| 会话 | 教学与采集容易视作同一件事 | 观察会话、教学会话独立；结束教学可保留仍有效的观察同意 |
| 上云 | 供应沙盒和媒体元数据预备链 | 连续本地观察；提问、显著变化、核验按需发送同帧本地脱敏画面 |
| 软件范围 | 固定流程及演示步骤 | 通用当前画面分析端口；Top20 只作为加速，不作为产品允许范围 |
| 操作主体 | 演示按钮推进固定阶段 | 用户亲手打开第三方软件、点击和输入；桌宠只指示，不注入输入 |
| 成功判定 | 点击“我点好了”推进的演示路径 | 自动变化与本人核验都须新鲜安全画面，旧标签或布局变化不直接等于完成 |
| 隐私恢复 | 预备风险门控 | 敏感、未知、检测故障先关出口、失效代次、停屏幕与指引；只能本人重新确认并复查 |
| 唤起 | 点击/文字与供应语音预备接口 | 点击可用；另接本机离线中文唤醒，不把云 ASR 用作未唤醒常听 |
| 学习闭环 | 通用笔记、待办、提醒仓储 | 每次教学独立安全摘要，默认未掌握；本人确认掌握、本人确认复习后调度 |
| 项目计划 | 96 工作包与开发/发布双门禁 | 保留工作包范围和依赖，改变运行边界及验收口径；不把正式 Go 缺失变成编码前置 |

## 运行与配置

从仓库根目录运行 `pnpm desktop`。请先通过旧应用自身的“退出桌宠”退出旧实例；单实例保护不会用第二个进程强行替换仍运行的旧代码。新启动默认不打开管理窗口、不抓屏、不启麦、不请求云端供应。打包成功只证明打包时快照；若共享宿主随后继续变更，不能把既有 out 包称为最新源码包。当前实际构建、字节一致性与回归结果以 `RUN.md` 为准。

在桌宠中直接提问、查看学习笔记，或右键查看功能。观察需本人选择来源及用途；云端分析同意与语音同意各自独立。不要把 Windows 系统权限失败当作产品授权已完成。停止观察入口同时停止本地语音；结束本次教学不等于停止观察。

桌宠服务连接由 `NUANBAN_DESKTOP_API_BASE_URL` 和 `NUANBAN_DESKTOP_API_TOKEN` 配置；token 是暖伴服务的有效设备会话凭证，不是供应密钥。供应只在服务端配置 `NUANBAN_VISION_BASE_URL`、`NUANBAN_VISION_API_KEY`、`NUANBAN_VISION_MODEL`。详情见 `standalone-guidance-provider.md`。不得把供应密钥放入桌宠 Renderer 或管理前端。

## 验证分层

### 本地画面过期与共享授权

完整通过本地隐私、完整性和来源检查但超过五秒有效期的画面，单独报告 `stale_frame`。运行核心丢弃该帧，在同一观察范围与既有授权下最多立即重采集两次；不修改真实 `capturedAt`，不延长有效期，也不重新弹出屏幕共享选择框。

重采集耗尽时，当前查找进入可手动重试的 `capture_error`，隐藏旧位置并关闭当前画面的发送资格；本地观察会话和用户已给出的屏幕、云分析授权仍保留。后续本地观察不自动重发该失败问题，用户可再次点击“查找并指引”。敏感、未知、检测不完整、画面损坏或时间校验失败仍立即停止采集并进入隐私暂停，需要本人处理后恢复。

### 验证范围

- 单元、契约、HTTP 回环及生命周期竞态测试使用合成依赖，不证明真实第三方软件或用户权限可用。
- `node scripts/test-standalone-desktop.mjs` 启动真实 Electron 和桌宠自身 UI，隔离用户数据，任何屏幕枚举/捕获尝试均直接拒绝；不打开麦克风，不调用真实供应。它证明默认关闭、管理与桌宠生命周期、加密记录和自身面板，不证明外部教学。
- `observation/probe-windows-observation.cjs --synthetic` 只用内存合成图实测本地 Windows OCR/人脸接口和遮盖；不读取用户桌面，不等于人脸检出率或通用软件覆盖验证。
- Android 独立运行时与 Windows 不是同一完成等级，实际编译、纯 Kotlin 测试、真机待项分别见 `apps/android/standalone-runtime.md`。
- 最终命令与结果在 `docs/execution/RUN.md` 更新；旧证据保留为历史，源码变化后需要重新运行指纹相关检查。

1. 本人系统授权后的真实外部屏幕、第三方应用操作及最终成功闭环；多屏、混合 DPI、遮挡、系统权限撤销与设备性能。

3. 真实供应配置、暖伴账号会话、成本/时延与视觉输出质量；不得用测试替身冒充真实模型。
4. 更广软件与未知页面的本地安全分类；当前保守规则会主动拒绝很多未验证页面，属于明确覆盖限制，不是已实现任意软件安全识别。
5. Android 真机上的模型初始化、检测时延/漏检、真实捕获、云断连、窗口坐标与穿透；本地适配器已有代码和编译证据，但缺就绪检测器或授权仍拒绝出口。
6. 真实系统提醒、亲情音视频、跨设备学习记忆、试点、签名发布和独立复核。

`development_ready` 即使在某次快照成立，也只表示当次本地开发检查满足；当前全量未通过，正式发布仍未批准。不得为“跑通”而放宽安全分类、伪造授权、自动同意采集或写入正式批准。
