# C04 受控媒体出口样例

这是 C04 / NV-07 的本地内存策略样例，不是 WebRTC、编码器或真实网络实现。它把 C03 的安全票据接到一个有界队列和两个本地测试出口（AI、家属）上，用合成 `NUANBAN-C04-SYNTHETIC` 元数据验证顺序和停止竞态。

- 不接收原始屏幕轨道，不调用摄像头/麦克风，不创建 `MediaRecorder`、WebRTC、WebSocket 或网络请求。
- 只有 `FrameSafetyGate` 允许的安全帧才进入编码器；编码器输入类型只含 frame id/hash、代际、策略版本、脱敏标记和合成 canary，不含 OCR 原文、像素或媒体轨道。
- 两个出口共享同一个 ticket 和 stop fence。AI 出口发送后发生风险/停止时，家属出口不能继续发送；队列有界，满时拒绝新帧。
- 编码器或出口失败会停止整个 relay，不自动重启。重启要求更高的新代际，旧帧和旧票据失效。

运行 `pnpm media:c04:check`。该检查只证明本地策略和竞态；真实端侧检测→编码→中继、双出口抓包/接收 canary、已发帧不可撤回和长时性能仍需 C15/E10/F07 资源。
