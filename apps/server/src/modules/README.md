# 微光指引 · 模块实施边界

> 文档同步：2026-10-22。产品显示名称为**微光指引**；[当前功能与平台边界](../../../../docs/implementation/product-current-state.md)统一说明现行入口、已实现范围和待验证能力。本文已有测试数字与生成日期仍只对应原批次，不因文档更新自动视为重新验收。

| 模块 | E 阶段职责 | 必须验收 |
|---|---|---|
| auth | 真实身份、设备密钥、令牌轮换、代注册认领 | 跨账号拒绝、撤销、监护 |
| family | 双方关系确认、分 scope 授权 | 关系不等于共享许可，撤权即时生效 |
| chat | 供应端口、SSE、风险策略 | generation 迟到事件、取消和上下文脱敏 |
| guidance | 受限候选步骤与核验摘要 | 不提供可执行点击，不接原始帧 |
| notes | 档案与掌握来源 | 对象鉴权、tombstone |
| todos | 时区、重复、提醒实例、幂等 | 重启恢复、去重、药物仅复述 |
| pets | 任务取消、扫描、确认后切换 | 不把静态晃动称为 AI 生成 |
| flows | 审核、版本、设备覆盖与回滚 | Top 20 清单未冻结前不得声称完成 |
| sync | outbox、版本、冲突与游标 | 账号代际隔离、离线重试 |
| assist | 邀请、授权、受控信令与 TURN | 不上传原始轨道、撤权优先 |
| audit | 白名单元数据 | 不落秘密、原图、人脸、音频 |
