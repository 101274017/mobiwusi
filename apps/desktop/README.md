# Windows Electron 宿主

产品默认桌宠已设为星云小猴子，不再是小橘猫。未联网时显示同款角色的本地透明静态预览；本人授权且星云返回有效资源后，切换为实时 3D。默认值不删除已有原画或本地模型，也不自动发起可能计费的云端连接。默认形象配置、凭证安全、独立功能页、停止清理及真实接口验收边界见 `../../docs/implementation/xingyun-avatar-integration.md`。只修改桌宠形象，不重排客户端界面。

桌宠面板按独立功能页切换：功能首页只列入口，点击提问、听写、搜索、光标指引、观察、学习记录、字幕或唤醒后，仅展示对应页面；顶部“全部功能”返回首页。“面对面语音”是直接会话入口：点击即收起功能小屋，完成本人确认后，只显示桌宠头顶的对话气泡与静音、打断、结束按钮；顶部“语音陪伴”仍可浏览说明。绘画、图片问答、3D 等继续打开各自的独立工具窗。切页保留未发送草稿，不自动授权、采集或发送；离开搜索会撤销本次联网确认并停止在途搜索，离开听写页会取消未完成的听写。隐私警告与全局停止入口跨页保留。

独立页面浏览器回归可运行 `pnpm exec playwright test --config tests/helpers/desktop-pet-playwright.config.ts`，覆盖 400×760 与 330×520 两种窗口，并检查气泡在 320×500 与 320×360 下的布局和结束按钮；没有下载 Playwright 浏览器时，可先设置 `PLAYWRIGHT_CHANNEL=msedge` 使用本机 Edge。


在仓库根目录运行 `pnpm desktop`。当前默认启动独立悬浮桌宠，管理窗口按需打开，关闭管理不退出桌宠。启动不抓屏、不启麦、不自动接业务后端。改版差异及验收边界见 `../../docs/implementation/standalone-pet-migration.md`。

桌宠底部“搜索”、功能页“智能查询”及右键菜单复用本机已配置的模型，与普通问答、教学共用模型实例、网关和加密凭证，不再需要 AnySearch 密钥，也不调用 AnySearch。本人确认后只发送当前手动问题；以纯文本展示“模型回答 · 未联网核验”，不把模型知识回答伪装成网页检索或来源。缺配置、鉴权失败和取消均如实提示，不回退演示、不自动重试。运行路径、隐私边界和验证方式见 `../../docs/implementation/pet-anysearch.md`。

桌宠底部“语音聊聊”、功能小屋“面对面语音”和右键“面对面实时语音…”均收起小屋，进入桌宠头顶气泡会话，不弹独立聊天窗口，也不需要管理客户端。未配置专用实时语音服务但已配置文字模型时，Windows 自动采用本机中文听写、已有模型文字回答、本机中文朗读，无需新增语音账号；本人另行同意后才开启，音频不上云，但文字和少量本次上下文发送现有模型，仍需网络与额度。该模式不创建语音窗口或 Renderer 媒体权限，朗读时停麦，以按钮打断，支持气泡字幕、静音关闭麦克风和结束。显式配置的云端 WebRTC 模式仅创建隐藏隔离音频宿主，支持开口打断，不会因故障静默切换模式。结束清除气泡文字，恢复普通悬浮桌宠，不自动展开小屋。配置与真实验收边界见 `../../docs/implementation/desktop-realtime-voice.md`。

原画可以通过“画一画 → 保存本机草稿 → 预览原画桌宠 → 直接设为桌宠”直接用作独立悬浮形象，无需 AI。支持重启恢复和恢复内置形象，操作与本机验证见 `../../docs/implementation/local-original-pet.md`。开发启动优先使用最新的 `apps/web/dist`；打包版本使用包内的 `ui`，不会因为上一次打包留下的旧界面而隐藏新功能。

文字、图片与只读桌宠教学可使用当前 Windows 用户配置的真实模型网关，配置方法见 `../../docs/implementation/real-ai-provider.md`。密钥通过 DPAPI 加密保存在仓库外，仅主进程解密。管理端默认为空白本机资料，Mock 业务、固定回答、模拟登录、家属连接和生成队列已移除；未接通服务明确不可用，测试替身不进入产品。

电脑端 3D 导入已接入“我的小伙伴”：选择本地 GLB / VRM / FBX → 隔离检查 → 旋转预览 → 确认设为独立桌宠，支持原画切回与重启恢复。格式限制、安全保护及验证命令见 `../../docs/implementation/local-3d-pet.md`；真实模型与跨显卡兼容仍需验收。

- renderer 禁用 Node，开启 contextIsolation / sandbox / webSecurity。
- 管理 preload 仅暴露受限管理桥；桌宠有独立受信 IPC，主进程核对实际窗口、主 frame 和固定本地页面。桌宠指引不控制外部应用。
- `standalone-host.cjs` 独立管理观察、教学、字幕、学习记录及本地语音；锁屏/退出等必须真实停止。结束教学可保留本人仍授权的观察，关闭管理不停止桌宠。
- 默认 session 禁止系统媒体权限与网络。本人选择后的媒体 worker 使用独立非持久 session、严格来源与权限处理，不放宽管理或桌宠 Renderer 的权限。
- 选定源捕获及本地 OCR/人脸脱敏代码已接入，但真实桌面/外部软件/系统授权尚未验收。来源、帧哈希、时效、代次与安全策略同时满足才允许按需发送；未知或检测失败停止屏幕及指引。
- 屏幕云分析仅走显式配置的主进程模型网关或原有鉴权业务端口，未配置不回退演示。本地唤醒/听写仅用离线引擎，未唤醒音频不上传，不自动改用云端。独立面对面语音另行本人同意：本地模式仅文字和少量上下文上云，云端模式 WebRTC 音频直连供应；均不与本地唤醒同时占用麦克风，不把云端语音声称为本地脱敏内容。
- 直接语音输入与持续唤醒分开：管理聊天的“语音 → 开始语音输入”及独立桌宠输入框旁的“语音输入”，都在原生窗口单独确认后立即听写，无需唤醒词。每次最多等待 20 秒，实际停麦后只回填发起输入框的草稿，不自动发送、不覆盖原文字；超出字数保留识别文字供本人整理。取消、收起输入面板、页面销毁或锁屏使迟到结果失效。已有唤醒会先关闭且不自动恢复；取消尚未同意的听写不撤销此前单独授权的唤醒。宿主或 preload 升级后需重新打开客户端才能加载新入口。自动化测试使用合成识别，不代表真实麦克风或识别准确率已经验收。
- 教学运行记录与原生提醒 payload 使用 `safeStorage` 加密；不是 SQLite 整库加密。学习档案与普通待办复用本机 IndexedDB，不声称已加密。系统通知权限仍保守报告，3D、WebRTC 与真实家属音视频均未验收。C02 样例仍是隔离的合成验证，不是核心产品的外部教学证据。
- `reminder-store.cjs` 在 Electron 主进程使用内置 SQLite 保存本地提醒，当前 schema 为 `v2`，支持 v1→v2 迁移、回执/完成/取消时间持久化和回执时间顺序保护，并通过受信任 IPC 提供排程、取消、回执和完成状态；不执行系统通知或后台调度。
- `notification-adapter.cjs` 是显式调用的桌面通知预备适配器：只在注入的 Electron `Notification.isSupported()` 和权限均明确可用时创建通知，记录 `submitted`/`delivered`/`opened`/`failed` 回执，并只打开受限 `nuanban://review/...` 或 `nuanban://todo/...` 深链；已通过 `reminder-notification-bridge.cjs` 在主进程受限装配；主进程当前将权限报告为 `unknown`，不会实际创建系统通知，不能替代系统后台调度证据。
- 根目录运行 `pnpm desktop:reminder-store:check` 可复现 9 项桌面仓储测试，结果见 `docs/implementation/evidence/desktop-reminder-store-results.json`。
- 根目录运行 `pnpm desktop:notification:check` 可复现 9 项桌面通知相关预备测试（5 项适配器、4 项主进程提醒桥），结果见 `docs/implementation/evidence/desktop-notification-adapter-results.json`。
- pnpm --filter @nuanban/desktop package 只生成开发包，签名和正式发布未验收。

## 可复现开发打包

### 桌宠功能首页

点击桌宠即可打开“暖暖的功能小屋”，也可右键选择“桌宠全部功能”。光标指引位于首页首个入口，并提供固定的功能导航；观察授权、逐步核验、重讲、结束教学、搜索、实时语音、本地听写、学习记录、复习确认、字幕和本地唤醒仍在桌宠中完成。普通功能浏览不启动屏幕或麦克风、不勾选上云用途，也不自动发送问题；“面对面语音”会收起小屋并请求本次本人确认，只有同意后才开始语音，活动期间不展开功能小屋。

“学习档案”和“待办与复习”直接使用桌宠内置页面，功能卡片、右键菜单以及旧的 /notes、/todos 工具调用都不会打开客户端或工具窗。学习档案支持搜索、掌握筛选、手写及编辑笔记、本人确认掌握、记录复习和确认删除；可直接给笔记安排关联复习。待办支持新增及修改、时间二次确认、每天/每周重复、到期/已完成筛选、确认删除、查看关联笔记和记录复习后完成。切页保留编辑草稿；完成待办或复习不自动改变掌握状态。

两页复用本机 local-owner 的 IndexedDB 资料；保存采用读后版本比较事务，资料变化时保留编辑草稿并拒绝覆盖，客户端同样防止旧快照覆盖桌宠资料。首次读取不填充演示内容；教学运行核心的加密记录仍保留在“桌宠学习记录”，不会自动复制到 IndexedDB。桌宠运行时每 15 秒读取到期待办，在桌宠底部显示入口；不申请系统通知、不提供退出后的后台提醒、不自动打开页面或联网。

文字与图片问答、绘画、桌宠形象、本地 3D、亲情、账号、无障碍、隐私、能力状态和资料冲突仍可从功能首页打开桌宠工具窗。工具窗复用现有安全页面和数据端口，隐藏客户端主导航，提供“返回桌宠全部功能”；返回先确认桌宠显示，再隐藏工具窗保留草稿。桌宠工具使用独立的按需窗口，不再复用或切换客户端主窗口；工作区身份由受信窗口确定，客户端始终保留原有导航、页面与草稿，不随桌宠工具打开或返回而改变。两个窗口的 IPC 仍逐一校验实际窗口、主框架及固定本地页面，关闭工具不会退出仍驻留的桌宠。高级管理仅保留为可选入口。

AI 生成桌宠、远程账号与亲情等未接通能力继续明确标注，不因增加入口而声称可用。源码、preload 或主进程改动需要在保存工作后重新启动暖伴才能加载；开发时不会自动重启正在运行的桌宠。专项单测与界面测试使用合成端口，不代表真实屏幕定位、麦克风、混合 DPI 或远程服务已验收。

运行 `node scripts/test-desktop-pet-isolation.mjs` 可在独立缓存目录中验证真实 Electron 窗口隔离：桌宠工具不覆盖客户端导航、页面与草稿，返回仅隐藏工具，两个窗口可分别关闭与重开。该检查只操作应用自有界面，禁止用户屏幕采集，不启麦克风，不代表真实外部软件或模型服务已验收，也不会重启正在使用的暖伴。

客户端左侧“打开桌宠”可显示桌宠，并恢复最小化或隐藏的窗口，不会因此开启屏幕观察或麦克风。客户端仍打开时，“关闭桌宠”先等待观察和语音实际停止，再隐藏桌宠；可随时从左侧重新打开。仅桌宠独立运行时，关闭桌宠仍退出应用；桌宠已关闭后再关闭客户端，也会正常退出，不留下无法唤起的后台窗口。

根目录运行 `pnpm desktop:package`：先构建共享 UI，再使用已安装且版本匹配的 Electron 本机分发文件创建 ZIP 缓存，交给 Forge 打包，不在打包阶段重复下载运行时。首次安装依赖仍需确保 Electron 二进制可用。

项目 `.npmrc` 使用 Forge 要求的 hoisted 依赖布局；只影响当前工程，不修改全局 pnpm 配置。本机缓存位于根目录 `.cache/electron`，已忽略。`pnpm install --offline --frozen-lockfile` 已在本机缓存条件下执行成功。

宿主运行时只依赖 Electron/Node 内置模块，UI 已打成静态资源，因此打包明确排除 node_modules，并关闭不必要的依赖裁剪扫描，避免把 Forge/Electron 安装器等开发依赖带进应用。

PowerShell 本地检测及离线唤醒脚本通过 ASAR 的 `unpack: '**/*.ps1'` 写入真实 `app.asar.unpacked`；宿主使用固定脚本路径解析，不向 PowerShell 传入虚拟 ASAR 内路径。对应 ASAR 生成与字节校验位于 `tests/platform/desktop-external-script.test.ts`。完整开发包仍须实际打包验证，不能只凭此项测试宣称已签名或已安装通过。

该命令不签名、不创建正式安装器、不自动运行桌面应用。窗口、浮层、多屏、采集、生命周期与远程媒体仍需 C 阶段设备验证；开发包存在不等于上述能力通过。

## C02 独立验证样例

根目录运行 `pnpm desktop:lab:check` 可隐藏运行锁定 Electron 的合成窗口检查；运行 `pnpm desktop:lab:package` 可生成未签名的独立 Windows x64 包；运行 `pnpm desktop:lab` 才会打开人工验证页面。样例只允许本机固定合成窗口来源，不枚举其他窗口、不采集桌面、不启用音频，帧只统计元数据并在本机停止。真实多屏、负坐标、混合 DPI、触摸穿透与系统授权仍未验收，详见 `native-lab/README.md`。
